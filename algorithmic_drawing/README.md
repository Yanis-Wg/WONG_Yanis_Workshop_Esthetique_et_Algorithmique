# Dessin Algorithmique

## Projet

Les dossiers atelier 1.* contiennent les exercices à réalisés par atelier selon le cours. 

L'atelier 1.2 a été réalisé selon un ses esthétique et dans l'idée que nous sommes les points. Que nous avons chacun écrits nos histoire et fait nos choix qui nous ont menés là où on en est et qu'on continue sans cesse à avancer. De plus le bézier représenterai le défilement du temps et le développement perpétuel de l'univers.

Pour voir le code, voir les fichiers sketch.js

## How to

Utiliser VSCODE & l'extension Five Server ou Live Server. Ouvrir le dossier atelier 1.* souhaité, faire un clique droit sur le fichier index.html et appuyer sur "Open with Live or Five Server". 

Regarder le résultat sur navigateur web.
