# Fractal

## Projet

Le dossier atelier 1.1 contient les exercices à réalisés pour le jour 3 du Workshop. 
Le dossier "comprehension et tests fractale" et l'analyse d'un code d'une fractale pour comprendre comment il marche, je l'ai commenté pour expliqué ce que j'ai compris.
Le dossier création fractale est un canva contenant 5 principale fractale dont la rotation change en fonction de la position de la souris sur le navigateur.

On peut faire un arret sur image en appuyant sur espace, en réappuyant sur espace le code se remet en marche, si on clique sur le canva, on a alors un fond blanc avec les fractales qui changent de couleur à l'infini.

L'idée de derriere cette fractale était de créer une fractale interactive que l'utilisateur peut manipuler et développer selon ses envies. Elle donne des motifs similaires à des motifs de tapis

Pour voir le code, voir les fichiers sketch.js

## How to

Utiliser VSCODE & l'extension Five Server ou Live Server. Ouvrir le dossier atelier 1.* souhaité, faire un clique droit sur le fichier index.html et appuyer sur "Open with Live or Five Server". 

Une fois sur le navigateur web.

Cliqué sur la "toile" ou le "canva" et découvrir l'oeuvre.
