# Fractal

## Projet

Le dossier creation libre contient l'exercice à réalisés pour le jour 5 du Workshop. 

Pour le derniere atelier du jour 5, j'ai souhaité mélanger deux tutoriels qui s'accordaient avec ce que je voulais faire. Je voulais jouer avec le son et les images en créant un lien entre eux. J'ai donc choisis des tutoriels que j'aimais visuellement bien. Ces deux tutoriels m'ont permis de gérer déplacement de point/ellipse sur un canva de maniere prédéfinis. J'ai également appris la gestion du son depuis le micro pour créer de l'interactivité avec l'utilisateur.

Plus on parle longtemps et fort, plus il y aura de point jusqu'à atteindre une certaine limite. Les points disparaissent par vague à un nombre de seconde prédéfini. Chaque milliseconde qui passe nous permet d'observer un dessin différent. Si on attend longtemps sans parler et ou faire de bruit, alors il n'y aura plus que un point sur la toile.

C'est pourquoi on peut faire un arret sur image en appuyant sur espace pour observer les formes. En réappuyant sur espace le code se remet en marche.

Pour voir le code, voir les fichiers sketch.js et mold.js

## How to

Utiliser VSCODE & l'extension Five Server ou Live Server. Ouvrir le dossier creation libre, faire un clique droit sur le fichier index.html et appuyer sur "Open with Live or Five Server". 

Une fois sur le navigateur web, amusez vous à faire du bruit ou à parler.

Si ca ne fonctionne pas, faire un clique gauche dans la page web et/ou attendre que le code charge (car utilise beaucoup de mémoire)

Cliqué sur espace pour découvrir votre oeuvre.
