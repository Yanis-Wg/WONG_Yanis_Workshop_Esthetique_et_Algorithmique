# WORKSHOP

## Projet

Les dossiers atelier 1.* contiennent les exercices à réalisés pour l'atelier du jour 4, digital litterature.

L'atelier 1.1 a était réalisés en comprenant et transcrivant le code python en code js.

L'atelier 1.2 a était réalisés en s'inspirant de matrix et sur le principe qu'a chaque clique une nouvelle phrase aléatoire s'affiche.

Pour voir le code, voir les fichiers sketch.js

## How to

Utiliser VSCODE & l'extension Five Server ou Live Server. Ouvrir le dossier atelier 1.* souhaité, faire un clique droit sur le fichier index.html et appuyer sur "Open with Live or Five Server". 

Regarder le résultat sur navigateur web.
